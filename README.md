## Core Experience

### 01. Linux / Infrastructure Automation

Linuxサーバの構築・運用に加え、**Ansibleを用いた運用自動化基盤の設計・構築**を経験しています。

- Linux初期構築・OS設定の自動化
- 複数サーバへの一括設定変更
- ソフトウェア導入・アップデートの半自動化
- サービス起動・停止の自動制御
- セキュリティパッチ適用
- repository同期
- cronによる定期運用
- inventory / roles / Playbook管理
- 自動化処理の障害調査・修正

要件変更によりAWSからIBM Cloudへ移行した案件では、Ansibleを活用してLinux構築部分をIaC化し、運用自動化を進めることで、**通常予定より約1か月早い納品**につなげました。

- VPC / Subnet / Route Table

また、**約52個のAWSアカウント**を扱う運用環境で、設定変更、監視、ログ確認、問い合わせ対応、障害切り分け、ドキュメント整備、誤操作防止、不要リソース・コスト確認などの運用改善にも取り組んでいます。

## Engineering Approach

与えられた作業をそのまま続けるのではなく、常に **「より良い方法はないか」** を考え、調査・検証し、必要に応じて周囲を巻き込みながら改善することを大切にしています。

特に、

- 手作業を自動化・標準化できないか
- 障害を復旧するだけでなく、再発を防止できないか
- 複数環境をより安全に運用できないか
- インフラだけでなくサービス全体として改善できないか

という視点で業務に取り組んできました。

今後も、Linux・クラウド・ネットワーク・仮想化・自動化の理解を深めながら、インフラからアプリケーションまで横断してサービス全体を考えられるエンジニアを目指しています。
